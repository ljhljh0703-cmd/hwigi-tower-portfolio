    휴식·전투·상점·엔딩 등 상황 14가지로 나눠 대화 697개를 만들었습니다.

    EXAONE 3.5 2.4B를 모델 일부만 고치는 방식(QLoRA)으로 Colab A100에서 학습했습니다.

  4. 시험과 게임 연결

    26턴 대화와 평가 20건으로 확인하고, Unity가 학습한 모델을 띄운 서버에 대화를 요청하게 연결했습니다.

모델을 바꾸기까지

실패 3번 · 버그 1개

  1. 문제

    처음 학습한 Qwen2.5 1.5B는 시험 9건 중 4건을 영어나 중국어로 답했습니다. "너 AI지?"에 "人工智能。"이라고 답하는 식이었습니다.

  2. 판단

    게임 밖 질문 데이터와 한국어로 답하라는 지시를 더 넣어도 그대로였습니다. 그래서 데이터를 늘리는 대신 한국어를 1순위로 배운 EXAONE 3.5 2.4B로 바꿨습니다.

    데이터 더 넣기
  3. 검증

    학습 도중 오류 없이 학습할 글자가 0개가 되는 버그를 찾아 고쳤습니다. 응답 앞 표시 뒤에 붙은 공백 하나 때문이었습니다.

  4. 결과

    26턴 대화 시험에서 25턴을 한국어로 답했습니다. 남은 1턴의 영어 응답도 결과표에 그대로 남겼습니다.

마타이오스가 지켜야 할 규칙호감도 · 스토리 단계 · 게임 밖 질문 · 말투

회귀자는 탑을 오른다는 Unity 6로 만든 Android 세로 로그라이크 프로토타입입니다. 마타이오스는 전투와 선택, 기억으로 플레이어 옆에 있다는 감각을 줘야 하는 동료입니다. 전투 중 행동은 규칙으로 처리했고, 이 페이지는 대화만 다룹니다.

  • 호감도 5단계(적대 · 냉담 · 보통 · 호의 · 열림)에 따라 말투가 달라집니다.
  • 게임 세계 밖 질문에는 캐릭터답게 선을 긋습니다.
  • 스토리 단계(S0~S4)와 기억 키워드에 따라 반응이 달라집니다.
  • S3 이후에는 자기 정체를 헷갈리는 말이 섞입니다.
  • 항상 한국어 반말을 씁니다.

게임과 연결한 구조Unity → 대화 서버 → 학습한 모델

EXAONE을 실행용 파일(GGUF)로 바꿔 Ollama로 돌리는 길은 안정적이지 않았습니다. 그래서 학습한 모델을 Python 서버(FastAPI + transformers)에 올리고 Unity가 HTTP로 대화를 요청하게 했습니다.
